Cannot-be-missed mechanic: the summary is pinned to the top of the board and its count only falls when a row is acted on or explicitly dismissed — scrolling never clears it, and the same number rides the Home tab. The track: N segments, hunter-defined

A hunter picks a template by gem type and edits the phase names from there, then marks which one is current. The track always renders one segment per phase, so tracks stay comparable across gems — "step 2 of 6" reads the same way as "step 3 of 4" — while each gem names its own phases. The label under the track carries the step count and the current phase name; segment labels are dropped, because five or six of them don't fit at 11px and the current phase is the only one a member needs read out.
