Mine — one question, one button

The tab answers "is my cycle running, and when do I collect?" before anything else is read. A cycle card leads with the status in words and a stated time, shows the cycle as a single ring filling around the mining core, and offers exactly one primary action whose label changes with the state — Start mining, then Claim. While a cycle runs there is no disabled button standing in for a status; there is a reminder toggle instead. Balance, Earn faster, Leaderboard and Hourly history sit below in that order, because the only way to mine faster is to invite friends who stay.

Why a progress ring is allowed here: the 24-hour cycle is Blocnet's own system, so the end time is known exactly. The rule against clocks and rails on Home and Hub is about third-party projects whose future nobody knows. Even so the card leads with the stated time and keeps elapsed hours secondary.
What is gone: mining power in TH/s, the orb and equaliser, the duplicated Total Earned / Claimed tiles, the day-long disabled Claim button, and the referral code's two-tap burial under Profile — it is now the Earn faster section, stated as the one thing that raises the rate.
Red budget: expiry and a closing claim window take amber, never red. Red stays moderation and destruction. Every state is words plus colour, never colour alone.

    The cycle card in five states, side by side

    The status word, the stated time and the ring are the same three elements every time. What changes is which of them is doing the work — and there is never more than one primary action.

    Idle
    pause_circleNOT MINING
    bolt

    One action: Start mining. The ring is empty, so the state is readable with the screen at arm's length.

    Mining
    boltMINING
    bolt

    No button. A reminder toggle instead, so a disabled control never stands in for a status for a whole day.

    Ready
    check_circleREADY
    check_circle

    Full. The amount moves into the button — Claim 132 BNP — and the edge breathes on a 3.2s cycle.

    Closing soon
    timerCLOSING SOON
    timer

    The ring flips meaning: the claim window draining, not the cycle filling. Amber, never red — the member has done nothing wrong, and red belongs to moderation.

    Expired
    timer_offEXPIRED
    timer_off

    Reported once, with date and amount, above a card that can start again. Grey, not amber — the window is closed, so urgency would be a lie.

    Motion, all of it: the running ring's glow breathes at 2.4s; the ready card's edge at 3.2s. Nothing else moves. Numbers render from data: 5 BNP an hour and 120 a cycle are admin-settable, so every figure on the card is composed from the rate and the boost, never baked into the layout.

    What is on the screen, and what is not

    Every number here is one the platform actually holds: accrued points, rate, boost, active friend count, lifetime claimed BNP, and the cycle's own timestamps.

    Removed

    Mining Power 10.0 TH/s — invented; nothing hashes.
    Total Earned / Claimed — two tiles for one number.
    Claim in 23:59:57 — a disabled primary button worn as a status for 24 hours.
    The orb and equaliser — motion with nothing to say.

    Never shown

    No USD value, no APY, no "estimated worth". BNP has no price today, and the only forward-looking statement on the screen is the one that is true: converts to BNT at launch.

    Moved here

    The referral code came up from two taps under Profile and became Earn faster, stated as the one mechanism that raises the rate. The friends list drops email addresses entirely: name, level badge, active or not.

    Hunter space

    Identical screen. Only the accent shifts to #22D3EE and tab slot 3 reads Hub instead of Community. Mining is a member behaviour, not a hunter privilege, so nothing else differs.
