Four ways to colour Blocnet

Mobile runs three spaces — User, Hunter, Moderation — and re-skins the whole app from one variable when you switch. Today User is blue, Hunter is cyan, and the console is a third blue that agrees with neither. This picks one system for all three.

Every phone below is the same screen and the same layout you ship today, re-skinned. Nothing here proposes new structure — that comes later, and it would only confuse the colour read. Flip the space toggle to see how each direction handles the split.

One correction worth having up front: the console's primary is oklch(0.67 0.17 268), which resolves to #698DFD — a periwinkle blue, not the violet I called it earlier. Your two palettes were never as far apart as that made them sound.

Recommendation

Signal Cyan, with the split done by intensity

Cyan is the only hue on this page you already own and nobody else is using. It survives the thing that kills most crypto palettes, which is that the accent has to work as a 4,000-instance UI colour and not just a logo.

The intensity split is the part that matters for your User and Hunter question:

  • One brand, two energies. Deep cyan for the everyday app, electric cyan for the Hunter space. Someone who sees either one still recognises Blocnet, which a two-hue system gives up.
  • The switch becomes felt, not just seen. Entering Hunter mode brightens and charges the same colour rather than swapping to a different brand. That is the moment worth designing.
  • Moderation stays red. It is not a third brand. It is an alarm, and it should feel like leaving the product.
  • Console follows mobile. Change one token and the admin finally matches the app.

If you want the safe answer instead, take Direction 02 — it is legible, it is cheap, and it costs you nothing but distinctiveness. I would not ship Direction 03 while green means success in your app.

Both files are already token-driven, so this is the whole colour migration. The 117 hardcoded hex values scattered across 22 Dart files are the separate cleanup — they are what stops a one-line change from being truly one line.
