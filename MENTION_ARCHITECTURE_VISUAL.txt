KEY REGEX PATTERN USED EVERYWHERE:
  @([a-zA-Z0-9._-]+)
  
  Matches:
  ✓ @john.doe
  ✓ @jane-smith
  ✓ @user_name
  ✓ @user123
  
  Does not match:
  ✗ @john@doe (no @ inside mention)
  ✗ @-invalid (can't start with dash)
  ✗ @user (with emoji) - emoji not allowed

DATA MODELS:

  MentionUserModel (Frontend)
  {
    id: string
    username: string
    displayName?: string
    avatarUrl?: string
  }

  CommentModel (Frontend - Update Comments)
  {
    id: string
    updateId: string
    authorId: string
    content: string (raw text with @mentions)
    createdAt: DateTime
    updatedAt: DateTime
    admin?: Admin
  }

  CommunityPostComment (Frontend - Community Comments)
  {
    id: string
    postId: string
    authorId: string
    content: string (raw text with @mentions)
    createdAt: DateTime
    updatedAt: DateTime
    admin?: Admin
  }

  Mention (Backend Database)
  {
    id: CUID
    mentionedUserId: string
    mentionText: string (@username)
    commentId?: string
    communityPostId?: string
    communityPostCommentId?: string
    createdAt: DateTime
    updatedAt: DateTime
  }
